
# Indiana State Expenditure Analysis | Power BI

## Project Overview

This project analyzes Indiana state vendor expenditure data from Q4 2025 using Power BI. The dashboard focuses on vendor concentration, agency-level spending, and government function allocation to identify spending patterns and procurement trends.

The project includes data cleaning and transformation in Power Query, DAX measures, and interactive dashboard development in Power BI.

---

## Dashboard Pages

### Vendor Spend Dashboard

This dashboard focuses on vendor concentration and procurement analysis, including:

* Total spend
* Vendor count
* Largest single vendor spend
* Average transaction amount
* Top vendors by total spend

### Agency and Government Function Analysis

This dashboard focuses on agency-level and functional spending trends, including:

* Number of agencies
* Median spend per agency
* Percentage of spend concentrated within the top 3 agencies
* Total spend by agency
* Spending distribution by government function

---

## Tools Used

* Power BI

## Data Preparation

The raw dataset was cleaned and transformed using Power Query. Steps included:

* Filtering and reducing unnecessary columns
* Correcting data types
* Handling null values
* Creating derived columns and measures
* Building summarized reporting tables

---

## Key DAX Measures

Examples of measures created for this project:

* Total Spend
* Median Spend per Agency
* Largest Single Vendor Spend
* Top 3 Agencies % of Spend
* Average Transaction Amount

---

## Key Insights

* Spending is heavily concentrated among a small number of agencies and vendors.
* The top 3 agencies account for 58% of total spend.
* Transportation represents the largest government function by expenditure.
* Vendor spend distribution shows strong concentration among the highest-funded vendors.
